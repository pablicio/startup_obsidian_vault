# 🌱 MVP não é produto pequeno — é experimento mínimo

A confusão mais comum com MVP: achar que é só reduzir o escopo do produto desejado.

Mas Ries é explícito: o MVP é o **menor experimento possível para testar a hipótese central**. Se a hipótese é "pessoas vão pagar por X", o MVP não precisa ser um software — pode ser uma landing page, uma ligação, um mockup estático.

O produto vem depois da validação, não antes.

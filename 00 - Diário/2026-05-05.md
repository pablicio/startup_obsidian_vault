## 📚 O que aprendi hoje?
> Active Recall — escrito sem olhar para os materiais.

- Eric Ries define startup como **experimento**: você não lança um produto, você testa uma hipótese. O MVP não é a versão menor do produto — é o menor experimento que valida ou invalida a premissa central.
- A diferença entre métrica de vaidade e métrica acionável está em se você consegue **tomar uma decisão diferente** com base nela. Pageviews não muda decisão. Retenção D7 muda.
- Zettelkasten e Lean Startup compartilham a mesma lógica: criar para aprender, não para acumular. O output é instrumento de validação, não produto final.

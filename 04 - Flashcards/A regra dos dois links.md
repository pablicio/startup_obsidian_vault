# 🃏 A regra dos dois links

## ❓ Pergunta

O que é a regra dos dois links e por que ela existe?

---

## ✅ Resposta

Toda nota permanente deve ter no mínimo **dois links** para outras notas do sistema.

A regra existe porque uma nota sem links não integra a rede — é um arquivo isolado. O valor do Zettelkasten vem das conexões, não do volume. Uma nota sem links pode ser boa em si mesma, mas não contribui para o efeito de rede.

Dois links é o mínimo suficiente para criar caminhos: um link entra, um link sai (ou dois pontos de encontro com ideias existentes). Se você não consegue encontrar dois links genuínos para uma nota nova, é sinal de que o conteúdo ainda não foi processado o suficiente — ou que a ideia ainda não está clara.

**Atenção:** links decorativos não contam. O link deve expressar uma relação real entre as ideias.

---

## 🧠 Mnemônico

> Nota sem link = ilha. Dois links = ponte de entrada e de saída.

# 📖 Como usar este vault — Guia de referência

> Este arquivo vive em `99 - Suporte/pages/` e serve como manual do sistema. Releia quando estiver em dúvida sobre onde colocar uma nota ou como o fluxo funciona.

---

## 🗂️ Estrutura das pastas

| Pasta | O que vai aqui | Quando usar |
|-------|---------------|-------------|
| `00 - Diário` | Notas diárias — intenção, tarefas, aprendizado, reflexão | Todo dia, ao abrir o vault |
| `01 - Caixa de Entrada` | Seeds — qualquer captura rápida ainda não processada | Ao longo do dia, sem filtro |
| `02 - Referências` | Notas bibliográficas de livros, artigos, vídeos, podcasts | Após terminar/pausar uma fonte |
| `03 - Permanentes` | Insights desenvolvidos com suas próprias palavras | Após processar uma seed ou referência |
| `04 - Flashcards` | Perguntas e respostas para revisão espaçada | Quando quer memorizar algo específico |
| `05 - Mapas` | MOCs — visão panorâmica de uma área temática | Quando um tema tem 5+ permanentes |
| `06 - Revisão` | Notas de revisão espaçada com Active Recall | Para conceitos que exigem compreensão profunda |
| `98 - Itens Arquivados` | Material processado, duplicatas removidas, notas obsoletas | Na revisão semanal |
| `99 - Suporte` | Templates, scripts, páginas de suporte do sistema | Raramente — administração do vault |

---

## 🔄 O fluxo básico

```
Captura (seed/inbox)
    ↓
Processar (revisão diária/semanal)
    ↓
Permanente (insight desenvolvido) ←→ Referência (fonte processada)
    ↓                    ↓
Flashcard         Mapa (MOC)
    ↓
Revisão espaçada
```

---

## ✍️ Regras das notas permanentes

1. **Título é uma afirmação**, não um tópico. Não "Lean Startup" — mas "Produto é hipótese antes de ser solução."
2. **Escrita com suas palavras**, após fechar a fonte.
3. **Uma ideia por nota.** Se você precisa de subtítulos para separar dois assuntos distintos, são duas notas.
4. **Mínimo dois links** para outras notas. Se não conecta com nada, pode não ser uma permanente ainda.
5. **Faz sentido sem contexto externo.** Alguém que abre a nota 2 anos depois deve entender sem precisar saber de onde veio.

---

## 🃏 Regras dos flashcards

- A pergunta deve ser atômica: testa uma coisa só
- A resposta deve ser verificável: ou você sabia ou não sabia
- O mnemônico é obrigatório quando a resposta é difícil de recuperar
- Revise com `Alt+E` — não manualmente

---

## 🔁 Ritual semanal (30–45 min)

1. Processar tudo da `01 - Caixa de Entrada`
2. Transformar seeds maduras em permanentes ou referências
3. Revisar notas com `proxima_revisao <= hoje`
4. Identificar conexões órfãs e linkar ou arquivar
5. Criar/atualizar Mapa se cluster ficou denso
6. Escrever revisão semanal em `99 - Suporte/pages/`

---

## 🧠 Princípios do sistema

> **"Você não está guardando informação. Você está construindo um interlocutor."**

- O valor do vault está nas conexões, não no número de notas
- Qualidade > quantidade — 20 permanentes densas > 200 rascunhos desconexos
- O sistema só funciona com uso consistente — 20 min/dia > 4h/semana
